No-Tie 0.1.2 — Android ARM64

Full debug APK for ARM64 Android tablets, including Lenovo Tab M11.
Android target API: 35; minimum API: 24.
Native library is packaged uncompressed, as in the previously working full APK.
Signed with the same Android debug certificate as 0.1.0 so it can update that install.

Install:
1. Download the APK directly, or download and extract the ZIP.
2. Open the APK on the tablet and allow installation from this source if Android asks.
3. Tap Install. Leave the previous No-Tie app installed when updating.

APK: No-Tie-0.1.2-android-arm64-full-signed.apk
